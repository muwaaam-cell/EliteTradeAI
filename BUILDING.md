## Build notes
No APK is included; only project source. An Android SDK/Gradle environment is needed to compile.
1. Transfer the ZIP to a computer with Android Studio, unzip it, and open the `EliteTradeAI` folder.
2. Let Gradle sync, then choose Build > Build APK(s).
3. The debug APK is normally in `app/build/outputs/apk/debug/app-debug.apk`.
If you only have Android, a free cloud build environment may be possible when its free allowance is available; don't add payment details. This project has not been compiled or device-tested here.
